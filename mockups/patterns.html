  • Groups are section headers, the same pattern as Supplements / Other factors in Protocol. Click a name to rename it, click the dot to change colour, drag the header to reorder groups.
  • Drag a symptom by its handle into another section to move it (shown mid-drag above). Order inside a group is your order.
  • On the phone, where long drags are awkward, each symptom has a Group menu instead. It is on desktop too.
  • + Add group at the bottom. Deleting a group never deletes symptoms; they drop into Ungrouped, which only shows when something is in it.
  • New symptoms get a suggested group from whatever name the person typed ("Bloating after meals" → Gut). A built-in word list handles the common ones instantly and offline; a small AI model handles anything it does not recognise. It is only ever a suggestion, marked ✦, and one tap changes it.
  • Few groups, on purpose. Four ship by default: Gut, Mood, Nerve & pain, Skin. Anything that fits none of them stays Ungrouped. Suggestions only ever pick from the groups you already have and never invent a new one, so the list stays short unless you add to it yourself.
  • Start from Intelligent copies the automatic groups in as a first draft for you to rename and correct, so you never start from a blank page. No AI call needed.
  • One symptom belongs to one group. There is still a single order underneath, so My order and My groups never disagree.

The three groupings

  • My order — stays. The flat list you have today, in the order you set.
  • My groups — sections you define (Gut, Mood…), managed in Edit symptoms (above).
  • Intelligent — automatic, from your last 90 days: symptoms whose bad days overlap are grouped, and a group gets a "flaring" badge when most of it is up.

How it behaves

  • Group headers collapse, and show how many are logged (2/3).
  • Rating, ↑/↓, jump-to-next-blank and the thumb scroll all follow whatever order is on screen.
  • Your choice is remembered. Nothing about the data changes; it is only a different sort of the same list.
