Audit — what’s wrong today

  1. The drawer header is hidden. The drawer is z-index 100, the nav is 200, so “Settings ✕” renders underneath the top bars. The only way out is clicking the dim area.
  2. Nine flat sections, no hierarchy. Account, Garmin, Preferences, AI Shortcuts, Recently Deleted, Backup, Data Tools, About, Danger Zone — all the same weight, ordered by when they were added, in a 520px column.
  3. The account card carries seven actions. Sync Now, Pull (merge), Restore…, Sign out, a snapshot list, a replace preview and a “(destructive)” text link. Buttons wrap to two lines.
  4. Three places to copy/export. Top-bar Copy, “Default copy range”, “AI Shortcuts” 30/60/90, plus “More options” — and two different things both called “Restore”.
  5. Every toggle is drawn twice in code (a desktop and a mobile variant of each option row), which is a big part of why the file is 2,168 lines.

Redesign — same rules as the nav

  • Layer 1 never changes. Settings is a page under the same top bar; the gear shows as active and no tab is selected.
  • Layer 2 = scope left, one primary right. “← Settings” on the left; sync status + the single Sync now on the right, visible from every section.
  • One grid. Rail + content sit in the same 1080px container as the bars.
  • One row pattern. Label + one-line description left, control right. Segmented controls for choices, one button per row, quiet secondary beside it.
  • Four sections by intent: General · Account & sync · Integrations · Data. About shrinks to two lines under the rail.
  • Rare and destructive things are collapsed, not deleted: Recovery tools and Danger zone open on demand.
