Audit — mobile today

  1. “More” looks like a tab but is a menu, and it isn’t contextual: “Edit Symptoms” is offered while you’re on Protocol.
  2. Two overflow menus. The ⋯ in the list bar (notes, edit, clear day) and More (notes, edit, copy, settings) overlap — notes and edit live in both.
  3. “Check for updates” is the first item in More — the rarest action in the best slot.
  4. Date chevrons sit at opposite screen edges with the score pill glued to the date; there’s no jump-to-today and relative labels hide the actual date.
  5. The bottom nav is see-through, so list rows bleed through the tab labels.
  6. Settings is one long scroll of nine cards, same problems as desktop, plus seven sync buttons wrapping in the account card.

What carries over

  • Layer 1 → floating tab pill. Three real destinations only. Never changes.
  • One overflow, not two. A single round ⋯ beside the pill opens a sheet: this tab’s actions first, app-level below, destructive last in red. The list-bar ⋯ and the More tab both go away.
  • Layer 2 → top bar. Same unified date stepper (with the real date), score ring on the right. Row two is progress left, the one primary action right (Check all on Protocol).
  • Insights follows the same slots: Comparison/Sleep where the date goes, range where progress goes.
  • Settings = the same four groups as desktop, as one grouped list. Choices stay inline as segmented controls; Recovery tools, Data and Danger zone drill in instead of expanding. Same removals (trend range, rename/delete supplement).
  • Not carried over: ⌘K search and the brand mark — no room and no keyboard. Search could live at the top of the ⋯ sheet if you miss it.
